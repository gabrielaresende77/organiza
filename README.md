# Organiza — Gerenciador de Tarefas

Projeto da disciplina de Programação I — Sistemas de Informação, UEMG.

## Objetivo

Organizar tarefas com responsável, prioridade e prazo, acompanhando sua conclusão em uma aplicação Java com interface gráfica Swing e conceitos de Programação Orientada a Objetos.

## Principais funcionalidades

- Cadastrar tarefas simples ou com checklist.
- Consultar por título ou responsável e filtrar pela situação.
- Editar título, responsável, prioridade e prazo.
- Excluir tarefas com confirmação.
- Atualizar a conclusão das tarefas e o progresso dos checklists.
- Identificar tarefas atrasadas e exibir um resumo das atividades.
- Validar campos obrigatórios e datas.

## Como executar

**Requisitos:** NetBeans e JDK 17 ou superior.

1. Abra o projeto no NetBeans.
2. Execute o projeto (F6).
3. Caso solicitado, selecione `tarefas.Aplicacao` como classe principal.

## Armazenamento

Os dados ficam apenas em memória, sem banco de dados. **Ao fechar o programa, as tarefas cadastradas são apagadas.**
